# 안녕하세요, 백엔드 개발자 유연수입니다.

Java와 Spring Boot 기반 웹 개발을 학습하며,  
데이터 흐름과 상태 관리를 고려한 백엔드 개발을 지향합니다.

## Tech Stack
- Java
- Spring Boot
- JSP/Servlet
- MyBatis
- Oracle DB
- JavaScript / AJAX
- Git / GitHub

## Projects

### recruit_prj | 채용 공고 웹 서비스
사용자, 기업, 관리자가 역할별로 채용 공고를 조회·지원·관리할 수 있는 웹 서비스입니다.

- 공고 검색 및 상세 조회
- 공고/기업 스크랩
- 중복 지원 및 마감 공고 지원 검증
- 기업 리뷰 평균 평점 및 페이징 조회
- 지원 정보와 첨부파일 매핑 처리

### movie_prj | 영화 예매 웹 서비스
영화 예매, 예매 내역 관리, 회원 정보 수정, 리뷰/문의 조회 기능을 제공하는 웹 서비스입니다.

- 마이페이지 기능 담당
- 예매 내역 조회 및 취소
- 예매 취소 시 좌석 상태와 잔여 좌석 수 동기화
- 회원 정보 수정 전 비밀번호 재확인
- 회원 탈퇴 Soft Delete 처리
