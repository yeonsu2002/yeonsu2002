## 📌 Projects

### 🔹 recruit_prj
**Spring Boot · MyBatis 기반 채용 공고 및 이력서 관리 웹 서비스**

- Controller - Service - Mapper 구조로 요청과 데이터 처리 로직 분리
- 마감 공고 지원 차단, 중복 지원 방지, 리뷰 권한 검증 등 서버 측 검증 로직 구현
- 지원 정보와 첨부파일을 하나의 트랜잭션으로 처리
- AJAX 기반 다중 조건 공고 검색 및 비동기 조회 구현

🔗 Repository : https://github.com/yeonsu2002/recruit_prj

### 🔹 movie_prj
**JSP · Servlet · JDBC 기반 영화 예매 웹 서비스**

- 예매 취소 시 예약 상태, 예매 좌석, 잔여 좌석 수를 함께 변경
- 회원 탈퇴 시 데이터를 삭제하지 않고 상태값을 변경하는 Soft Delete 적용
- AJAX를 이용한 예매 상세 정보 모달 조회 구현
- 회원정보 수정 전 비밀번호 재확인 적용

🔗 Repository : https://github.com/yeonsu2002/movie_prj
