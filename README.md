## 📌 Projects

### 1. Recruit Project | 채용 공고 웹 서비스
사용자, 기업, 관리자가 역할별로 채용 공고를 조회·지원·관리할 수 있는 웹 서비스입니다.

🔗 Repository: [recruit_prj](https://github.com/yeonsu2002/recruit_prj)

**주요 기능**
- 채용 공고 검색 및 상세 조회
- 공고/기업 스크랩 등록 및 해제
- 중복 지원 및 마감 공고 지원 검증
- 기업 리뷰 평균 평점 및 페이징 조회
- 지원 정보와 첨부파일 매핑 처리

**핵심 경험**
- 서버 검증을 통한 비정상 요청 방지
- 공고, 기업, 기술스택, 리뷰 데이터를 활용한 SQL 조회
- Controller - Service - Mapper 구조 기반 기능 구현

<br/>

### 2. Movie Project | 영화 예매 웹 서비스
영화 예매와 마이페이지 기능을 제공하는 JSP/Servlet 기반 웹 서비스입니다.

🔗 Repository: [movie_prj](https://github.com/yeonsu2002/movie_prj)

**주요 기능**
- 예매 내역 조회 및 예매 취소
- 예매 상세 모달 비동기 조회
- 회원 정보 수정 전 비밀번호 재확인
- 회원 탈퇴 Soft Delete 처리
- 관리자 회원 조회 및 검색

**핵심 경험**
- 예매 취소 시 좌석 상태와 잔여 좌석 수 동기화
- AJAX를 활용한 예매 상세 조회
- 회원 상태값 관리를 통한 데이터 보존
